## 一、架构与框架

### Q：用 3–5 句话解释 Vaadin / Spring Boot

**Vaadin：** 用 Java 写 UI 的 Web 框架。每个页面是一个 Java 类（View），继承 VerticalLayout 等组件，通过 `@Route` 映射 URL。浏览器端 Vaadin 自动同步 DOM，不需要写 React/Vue。

**Spring Boot：** 提供依赖注入、Security、JPA。View 构造器注入 Service，Spring 自动创建 Bean。

**本项目：** View 在 `com.hcbs.web.*`，Service 在 `com.hcbs.service.*`，数据库 H2。

### Q：Vaadin 组件 + 对应代码

| 推荐答案 | 文件 | 代码位置 |
|---------|------|---------|
| 自定义座位图 | `booking/component/SeatMapPicker.java` | `seatButton()`、`toggleSeat()` |
| 数据表格 Grid | `home/FilmDetailView.java` | `Grid<ShowingRow>` + Book 列 |
| 下拉 ComboBox | `home/component/AdditiveShowingFilterPanel.java` | city/cinema ComboBox |
| 登录表单 | `auth/LoginView.java` | TextField + PasswordField |

### Q：Spring 在本项目中的作用

- **依赖注入：** `BookingView(BookingService, CurrentUserService)` 构造器注入
- **Security：** LoginView + `@RolesAllowed` 控制页面访问
- **事务/持久化：** Service 层操作 Repository（View 不直接接触）

## 二、功能实现与逻辑

### Q：Login 怎么实现？

📄 详见 [auth/README.md](auth/README.md)

1. 用户填手机号、密码
2. `submitLogin()` → `HttpServletRequest.login()`
3. Spring Security 验证 → 成功 navigate 到 redirect 或首页
4. 触发事件：**Sign in 按钮 click**

### Q：订票怎么实现？

📄 详见 [booking/README.md](booking/README.md)

1. 进入 `/booking` 或带 `?showingId=`
2. `beforeEnter` 检查登录
3. `BookingService.findBookingContext` + `listSeatMap`
4. 用户点座位 → `SeatMapPicker` 选中
5. Confirm → `BookingService.createBooking`
6. 触发事件：**beforeEnter、座位 click、Confirm click**

### Q：管理导航栏的文件？

📄 **`shell/MainLayout.java`**

- 侧栏：`refreshDrawer()` 第 109–130 行
- 顶栏：`refreshHeader()` 第 88–106 行

### Q：员工和客户看到不同页面吗？

**是。** `MainLayout.refreshDrawer()`：

| 角色 | 侧栏 |
|------|------|
| 未登录 | 仅 Home |
| CUSTOMER | Home + My bookings |
| STAFF | Home + Book tickets + Cancellation |
| ADMIN | 上述 + Data admin |

### Q：某流程用到哪些文件？

#### 浏览 → 订票 → 取消

| 步骤 | 文件 |
|------|------|
| 主页 | `home/FilmRecommendView.java` |
| 筛选 | `home/component/AdditiveShowingFilterPanel.java` |
| 详情 | `home/FilmDetailView.java` |
| 订票 | `booking/BookingView.java` + `SeatMapPicker.java` |
| 取消 | `cancellation/CancellationView.java` 或 `MyBookingsView.java` |
| 导航 | `shell/MainLayout.java` |

#### 未登录订票

| 步骤 | 文件 |
|------|------|
| 拦截 | `booking/BookingView.beforeEnter()` |
| 登录 | `auth/LoginView.java` |
| 跳回 | LoginView `submitLogin()` 读 redirect |

## 三、Java 语法

### Q：某方法的返回类型和参数？

以 `BookingService.createBooking` 为例（Service 层，View 调用处）：

```java
// BookingView.confirm() 中：
BookingReceipt bookingReceipt = bookingService.createBooking(activeShowingId, seatIds, phone);
```

- 返回：`BookingReceipt`（DTO）
- 参数：`Long showingId, List<Long> seatIds, String phone`

View 层示例：

```java
// ShowingFilterQuery.java
public static QueryParameters toQueryParameters(ShowingListingFilter filter)
public static ShowingListingFilter fromQueryParameters(QueryParameters queryParameters)
```

### Q：Lambda 表达式例子

```java
// FilmRecommendView — 方法引用
filterPanel = new AdditiveShowingFilterPanel(searchService, this::runSearch, this::showAllFilms);

// BookingView — lambda
confirm = new Button("Confirm booking", e -> confirm());

// MainLayout — lambda
account = new Button("Account", event -> openAccountCenter());

// SeatMapPicker — lambda
chip.addClickListener(e -> onShowtimeSelected.accept(option.showingId()));
```
