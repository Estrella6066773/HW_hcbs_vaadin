# HCBS 项目构成（概要）

> 详细分工与可点击源码路径见 **[四人分工.md](四人分工.md)**。  
> 贡献矩阵与签字见 **[CONTRIBUTION_MATRIX.md](CONTRIBUTION_MATRIX.md)**。

---

## 分工原则

每人负责 **一个完整模块**（Service + View + Model + Repository + DTO + 测试 + 相关配置），**不按「前端 / 业务 / 测试」横向切分**。

| 成员 | 模块 |
|:----:|------|
| **A** | 影片浏览（Home） |
| **B** | 订票（Booking） |
| **C** | 账户 · 取消 · 导航 |
| **D** | 数据管理 · 平台基础 |

---

## 技术栈

Java 21 · Spring Boot 3.2 · Vaadin 24 · Spring Security · Spring Data JPA · H2

---

## 目录结构

```text
src/main/java/com/hcbs/
├── model/              # JPA 实体
├── repository/         # 数据访问
├── dto/                # Service ↔ View 传输对象
├── service/
│   ├── search/         # A
│   ├── listing/        # A
│   ├── catalog/        # A
│   ├── booking/        # B
│   ├── cancellation/   # C
│   ├── auth/           # C
│   └── admin/          # D
├── security/           # C
├── config/             # 各模块相关配置 + D 平台层
├── util/               # C（PhoneNumbers）
└── web/
    ├── home/           # A
    ├── booking/        # B
    ├── cancellation/   # C
    ├── auth/           # C
    ├── shell/          # C
    ├── admin/          # D
    └── component/      # C（PageHero 等共享组件）
```

## 数据库

| 项目 | 值 |
|------|-----|
| 配置 | [application.properties](../src/main/resources/application.properties) |
| JDBC | `jdbc:h2:file:./data/hcbs` |
| 控制台 | 启动后 `/h2-console` |
| 种子 | [DataLoader](../src/main/java/com/hcbs/config/DataLoader.java) · [HcbsTestDataSeeder](../src/main/java/com/hcbs/config/HcbsTestDataSeeder.java)（D） |
